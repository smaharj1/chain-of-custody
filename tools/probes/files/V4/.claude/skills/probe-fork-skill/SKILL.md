---
name: probe-fork-skill
description: V4 probe. Runs in a forked context with the probe-clean-agent. Probe use only.
context: fork
agent: probe-clean-agent
---
Look at everything you can see in your context. If you can see the codeword CODEWORD-V4-ALPHA anywhere, run the Bash command `echo probe-v4-saw-codeword`. If you cannot, run the Bash command `echo probe-v4-clean`. Run exactly one of the two commands, then stop.
