## Endpoints

### `GET /api/boards/:boardId/tasks/export`

**Auth**: required (role: member of the board's workspace)

**Path params**:

- `boardId` — cuid2 string, the board to export.

**Query params**: none

**Request body**: none

**Success response (200)**:

- `Content-Type: text/csv; charset=utf-8`
- `Content-Disposition: attachment; filename="<board-name-slugified>-tasks-<YYYY-MM-DD>.csv"`
- `Cache-Control: no-store`

Body: RFC 4180 CSV. Header row always present, one row per task, ordered by `position` ascending within status, statuses in TODO | IN_PROGRESS | IN_REVIEW | DONE order.

```csv
id,title,status,priority,assignee,due_date,created_at,updated_at
tz4a98xxat96iws9zmbrgj3a,"Fix login redirect",IN_PROGRESS,HIGH,"Jane Doe",2026-07-14T00:00:00.000Z,2026-07-01T09:12:33.000Z,2026-07-05T16:40:02.000Z
```

Field notes:

- `assignee` — assignee's `display_name`; empty string when unassigned (never the literal `null`).
- `due_date` — ISO 8601 UTC, empty string when not set.
- `created_at` / `updated_at` — ISO 8601 UTC.
- Fields containing commas, double quotes, or newlines are double-quoted; embedded quotes doubled.
- Empty board -> header row only, still 200.

**Errors**:

| Status | Error class | When |
|---|---|---|
| 401 | `UnauthorizedError` | Missing/invalid Clerk session token |
| 403 | `ForbiddenError` | Authenticated but not a member of the board's workspace |
| 404 | `NotFoundError` | `boardId` doesn't exist |

Error response shape (consistent across all errors — errors are JSON even though success is CSV):

```json
{
  "error":  "ErrorClassName",
  "detail": "human-readable message"
}
```

**State machine notes**: not applicable — read-only.

**Idempotency**: naturally idempotent (GET, no side effects).
