```json
  "field3":  "number — integer cents for money, or description of format"

```

**Success response (201)**:

```json
{
  "id":         "string",

```

| Status | Error class | When |
|---|---|---|
| 400 | `ValidationError` | Body fails validation |
| 401 | `UnauthorizedError` | Missing/invalid token |
| 403 | `ForbiddenError` | Authenticated but wrong role |
| 404 | `NotFoundError` | Referenced resource doesn't exist |
| 409 | `ConflictError` | Duplicate key / state conflict |

Error response shape (consistent across all errors):

```json
{
  "error":  "ErrorClassName",
  "detail": "human-readable message"
}
```
